# Security Policy

## Supported versions

Only the latest commit on `main` receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security reports.

- Use GitHub's private vulnerability reporting
  (**Security → Report a vulnerability**), or
- Contact the repository owner directly.

Include: affected area (route/component/endpoint), reproduction steps
and impact assessment. You will receive an initial response within 7 days.

## Scope notes

This is a learning project, but the review bar is real:
`src/content/docs/docs/architecture/security.md` records implemented controls, platform
delegations and deferred items with their triggers.
